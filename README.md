The official privacy policy page for **Blitzy**, a Chrome extension for tab management and per-site time tracking. A single self-contained `privacy.html` — no build step, no dependencies, ready to host.

## Screenshots

> 📸 Screenshots coming soon — open `privacy.html` in any browser to see the page live.

## Features

- 🛡️ **Complete privacy policy** — data collection, usage, sharing, and user controls
- ✨ **Maximalist dark UI** — animated aurora background, particle field, glowing shield emblem
- 🔊 **Synthesized SFX** — subtle hover ticks and click blips via WebAudio (mutable, one tap)
- 📱 **Responsive** — clean on mobile and desktop
- ♿ **Accessible** — respects `prefers-reduced-motion`, semantic HTML, keyboard-friendly
- 📦 **Zero dependencies** — one HTML file; fonts via Google Fonts CDN

## Usage

Just open it:

```bash
# preview locally
python3 -m http.server 8000
# → http://localhost:8000/privacy.html
```

Or host it — see [HOSTING.md](HOSTING.md) for GitHub Pages / Drive / web-host instructions, plus how to link it from the Chrome Web Store listing.

## Project structure

```
privacy.html    The policy page (styled, interactive)
HOSTING.md      How to host it + Chrome Web Store linking
assets/         Banner art
```

## Customizing

The policy text lives directly in `privacy.html` — edit the sections in place. Remember to update the **Last updated** badge date and the contact email when you make changes.
